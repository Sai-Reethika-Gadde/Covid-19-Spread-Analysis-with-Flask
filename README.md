## Setup and Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sai-Reethika-Gadde/Covid-19-Spread-Analysis-with-Flask.git
   ```

2. Open the project folder:

   ```bash
   cd Covid-19-Spread-Analysis-with-Flask
   ```

3. Create and activate a Python virtual environment:

   ```bash
   python -m venv venv
   ```

   On Windows:

   ```bash
   venv\Scripts\activate
   ```

4. Install the required packages if `requirements.txt` is available:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the Flask application using the correct Python entry-point file:

   ```bash
   python app.py
   ```

6. Open the local URL displayed in the terminal in your browser.
